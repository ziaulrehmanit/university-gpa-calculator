# University GPA Calculator

A robust C++ console utility designed to calculate a university student's semester GPA based on custom course inputs, individual credit hour allocations (theory vs. practical split), and standard grade distributions.

## 🚀 Features
- **Smart Validations:** Automatically handles invalid menu choices or non-numeric entries, terminating safely to prevent memory loops.
- **Dynamic Calculation:** Automatically tracks and computes percentages, standard 4.0 scale letter grades, and total weighted GPA.
- **Clean Results Output:** Formats your final transcript neatly inside the terminal window using structural padding.

## 💻 How to Run
1. Clone this repository or copy the code from `main.cpp`.
2. Compile the file using any standard C++ compiler (like GCC or Clang):
   ```bash
   g++ main.cpp -o gpa_calculator
   ```
3. Run the executable terminal file:
   ```bash
   ./gpa_calculator
   ```
